# 山光 / Hill Light

同一座山，四时的光。为中文长文准备的四时阅读主题：晓雾、午荫、暮烟、夜月。版式、字号与构图不动，只改纸面、墨色、雾和受光面。

## 仓库

| 仓库 | 用途 |
| --- | --- |
| [hill-light-theme](https://github.com/hill-light/hill-light-theme) | 核心规范、CSS 变量、静态演示站与对比度检查 |
| [hill-light-quarto-book](https://github.com/hill-light/hill-light-quarto-book) | Quarto Book 扩展：侧栏、章节导航、页导航 |
| [hill-light-quarto-website](https://github.com/hill-light/hill-light-quarto-website) | Quarto Website 扩展与演示站 |

## 在线

- [主题站](https://hill-light.github.io/hill-light-theme/)
- [Book 模板](https://hill-light.github.io/hill-light-quarto-book/)
- [Website 模板](https://hill-light.github.io/hill-light-quarto-website/)

三个仓库共享同一套语义变量。色值先改 `css/tokens.css` 和 `DESIGN.md`，再同步到两个扩展，避免各自漂移。
